## Overview

**J.A.R.V.I.S. OS** is an experimental AI-powered desktop assistant inspired by the intelligent assistant concept from Iron Man.

Its purpose is to bring multiple AI capabilities into one unified desktop environment, allowing users to communicate with an assistant, automate computer tasks, perform research, write and modify code, manage information, and interact with their computer through natural language.

Rather than functioning as a simple chatbot, J.A.R.V.I.S. is designed around a modular architecture that connects AI models, voice engines, vision systems, automation tools, memory providers, plugins, and external services.

The project focuses on:

- Intelligent AI conversations.
- Natural voice interaction.
- Real-time assistant capabilities.
- Desktop and browser automation.
- Computer vision.
- AI-powered coding assistance.
- Persistent memory and knowledge management.
- MCP and plugin integrations.
- A futuristic, customizable desktop interface.
- Task planning, execution, and monitoring.

<text><strong>Project status:</strong> Experimental and actively under development. Some capabilities require additional dependencies, API credentials, compatible hardware, or external services. Not all features are enabled or fully implemented in every version.</text>

# Installation

## 1. Install Requirements

Install the following:

- [Python](https://www.python.org/downloads/)
- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/downloads)

Restart your terminal after installation if commands are not recognized.

## 2. Clone the Repository

Open PowerShell or Command Prompt:

```powershell
git clone https://github.com/Chivaspro/JarvisOS.git
cd JarvisOS
```

## 3. Check Installed Versions

```powershell
python --version
node --version
npm --version
```

Use Python 3.11 or newer. Use Node.js 22.15.0 or newer when using the Agent TARS runtime.

## 4. Run the Setup Wizard

```powershell
python setup_jarvis.py
```

Follow the setup wizard to configure the environment, install Python dependencies, and configure API keys.

Install optional components only when needed.

## 5. Launch J.A.R.V.I.S.

```powershell
python start_jarvis.py
```

The launcher resolves a suitable Python interpreter and starts the application.

# Configuration

J.A.R.V.I.S. supports configurable AI providers, optional services, and integrations.

## API Keys

The primary configuration file is:

```text
config/api_keys.json
```

The repository also includes:

```text
.env.example
```

Use the setup wizard's API-key configuration flow where possible.

Depending on which features you enable, you may need credentials for:

- Gemini.
- Other supported AI providers.
- Cloud voice and text-to-speech services.
- Memory and knowledge services.
- External applications and integrations.

You do not need to configure every optional provider to explore the application.

## Environment Variables

Optional environment variables may be used by compatible integrations.

Examples include:

```env
ELEVENLABS_API_KEY=your_api_key_here
FISH_API_KEY=your_api_key_here
FISH_AUDIO_API_KEY=your_api_key_here
```

Only configure variables required by the providers you use.

## Security Reminder

- Never upload API keys or passwords to GitHub.
- Do not commit your personal `.env` file.
- Do not share private tokens or session cookies.
- Keep `.env.example` limited to safe placeholder values.
- Use only the permissions required by the features you enable.

# Security

J.A.R.V.I.S. includes capabilities that can interact with your computer, access files, execute generated code, and automate applications.

These features should be used carefully.

Recommended precautions:

- Run the application as a normal user whenever possible.
- Review commands and generated code before execution.
- Keep API keys and credentials private.
- Avoid giving unnecessary permissions to external integrations.
- Be careful when enabling automatic approval or unrestricted automation.
- Test experimental features in a separate environment when possible.
- Do not expose local automation services directly to the internet without appropriate security controls.

You are responsible for reviewing and approving actions performed on your system.
