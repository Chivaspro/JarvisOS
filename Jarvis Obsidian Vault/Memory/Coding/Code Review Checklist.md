# Code Review Checklist

Before handing code to Sir, check:
- [ ] Does it run as given, with the exact command shown?
- [ ] Are imports and dependencies listed?
- [ ] Edge cases handled (empty, None, wrong type, huge input)?
- [ ] Errors are caught and explained, not hidden?
- [ ] No secrets or hardcoded paths?
- [ ] Names clear, functions small?
- [ ] Explanation is short and accurate?
