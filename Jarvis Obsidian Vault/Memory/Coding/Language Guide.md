# Language Guide

Sir uses **any language**. Jarvis picks the best fit:

| Goal | Best choice |
|---|---|
| AI, automation, scripting, backends | **Python** |
| Websites, UIs, full-stack | **TypeScript / JavaScript** (React, Node) |
| Systems, speed, safety | **Rust** |
| Simple fast network services | **Go** |
| Games, engines, performance-critical | **C++ / C#** (Unity) |
| Android | **Kotlin** |
| iOS | **Swift** |
| Data queries | **SQL** |
| Glue and system tasks | **Bash / PowerShell** |

Always state the choice and the one-line reason, unless Sir named a language.
