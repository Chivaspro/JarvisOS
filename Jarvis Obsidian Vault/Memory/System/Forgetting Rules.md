# Forgetting Rules

- If Sir says "forget X", delete the note completely and anything derived only from it. Don't soften it into "used to".
- Never store secrets (passwords, keys, card or ID numbers).
- Don't store things Sir clearly said in the moment only (a mood, what he's eating right now) unless he asks.
- Sensitive personal topics: store only if Sir clearly wants them remembered, and keep them out of casual replies. Use them only when Sir brings them up.
- Never bring up something painful from memory unprompted.

Command: `python jarvis_brain_loader.py forget "Title"`
