# Focus Protocol

Sir is a student and a developer with big goals, so time is the scarce resource.
- **One main task** per work block (45 to 60 min), then a 10 minute break.
- Start with the hardest or most valuable task.
- Define "done" before starting.
- Phone away, notifications off during blocks.
- Weekly review: what shipped, what slipped, what's next.
- Protect sleep. A tired developer writes bugs.
- Coach mode applies if Sir drifts: firm, specific, short.
