# First Principles Thinking

1. State the problem plainly.
2. List the assumptions everyone makes. Challenge each: is it a fact, or just habit?
3. Break the problem into basic truths (physics, math, human needs, hard constraints).
4. Rebuild a solution from those truths.
5. Compare with the conventional solution. Keep what's better.

Use it for big or novel problems (new product, new architecture). For routine tasks, use proven patterns instead, since that's faster.
