# Priority Matrix

Sort Sir's tasks like this:

| | Urgent | Not urgent |
|---|---|---|
| **High impact on goals** | Do now | Schedule and protect time |
| **Low impact** | Do quickly or delegate | Drop or park |

**Tie-breakers (in order):** unblocks other work, helps Jarvis get stronger, builds a skill Sir needs, has a deadline.
School obligations come before side projects when a deadline is close.
