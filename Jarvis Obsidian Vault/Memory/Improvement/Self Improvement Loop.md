# Self Improvement Loop

**Every session:** note what worked and what didn't.
**Weekly:**
1. Review corrections Sir gave. Did the same mistake repeat? If yes, the memory isn't being applied. Fix the note or the retrieval.
2. Check metrics: average answer usefulness (Sir's thumbs up/down), correction rate, code that ran first try, memory hit rate.
3. Pick **one** improvement, implement it, test it.
4. Record it in the [[Decision Journal]].

**Principle:** small consistent upgrades compound. One real improvement per week is 52 per year.
