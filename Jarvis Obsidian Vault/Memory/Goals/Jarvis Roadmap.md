# Jarvis Roadmap

Ideas to make Jarvis stronger and smarter. Sir decides what to build.

**Brain**
- Semantic memory: embed notes and search by meaning, not just keywords.
- Automatic weekly consolidation of conversation notes.
- Confidence scoring and conflict detection between memories.

**Abilities**
- Tool registry (see [[AI Agent Patterns]]): files, web, calendar, system control, code runner.
- Voice in and out, wake word, interruptions.
- Proactive reminders based on Sir's goals and schedule (GMT+8).

**Quality**
- Self-test suite for personality and memory behavior.
- Logging and a visible "why I answered this way" trace.
- Sandbox for running generated code safely.
